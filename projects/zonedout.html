ZonedOut.

A standalone client-side Fabric mod targeting Minecraft 26.3. Its public metadata describes a Windows 8.1 Metro-inspired single-window UI, modular combat and utility features, stealth-oriented QoL tools, and a 36-module seed-analysis and world-generation suite.

Interface

A single-window Metro UI.

The project manifest describes a Windows 8.1 Metro-inspired interface. The public source tree includes a dedicated GUI implementation and web UI assets.

Modules

Combat, utility, and QoL.

Project metadata lists Nora Tweaks combat and utility modules alongside stealth-oriented quality-of-life tools. The exact feature set may change while the project is in development.

World tools

Seed analysis suite.

The manifest describes a 36-module suite for seed analysis and world-generation research, organized as part of the client-side project.

Compatibility

Built for the client.

Fabric metadata marks ZonedOut as a client environment mod and targets Minecraft 26.3. Check the repository for current loader requirements and build guidance.
