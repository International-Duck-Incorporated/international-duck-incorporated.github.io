NullTrace.

NullTrace is a client-side Fabric mod that reduces the information Minecraft servers can use to identify, fingerprint, or track a modded client. It started from OpSec's client-side privacy work and now runs its own codebase, branding, and version support for Minecraft 1.21.11, 26.1, 26.2, and 26.3.

Protection surface

What it defends.

  • Client brand spoofing with vanilla-like reporting
  • Network-channel, known-pack, and key-resolution filtering
  • Resource-pack cache isolation and local URL protection
  • Server-pack control with MANUAL, ASK, and ALWAYS ON modes
  • Chat signing, telemetry blocking, and account switching
Scope

Honest boundaries.

NullTrace does not make you anonymous. It does not hide your IP address, server-side activity, or every fingerprinting technique. It is specifically focused on reducing common client-side fingerprinting and tracking surfaces.

Diagnostics

Stay informed.

  • Alerts, toast notifications, and detection logging
  • Optional /nulltrace debug command, disabled by default
  • Configuration through the multiplayer screen or Mod Menu
  • Whitelist modes for mods that talk to servers on purpose
How it works

A layered privacy workflow.

NullTrace focuses on specific client-side signals instead of promising anonymity it cannot provide.

01

Inspect the connection

Connection posture and known fingerprinting surfaces are evaluated when joining a server, before normal play produces additional client signals.

02

Reduce exposed signals

Brand reporting, network channels, known packs, key resolution, telemetry, and selected resource-pack behavior can be filtered or isolated.

03

Keep control visible

Alerts, logs, configuration screens, and optional diagnostics make active protections understandable rather than silently changing behavior.

Controls

Designed for different trust levels.

Settings can be adjusted for a server instead of forcing one global policy onto every connection.

Manual

Keep potentially identifying behavior behind an explicit user action. This is the most deliberate option for unfamiliar servers.

Ask

Prompt when a protected action needs a decision, providing context without permanently blocking the workflow.

Always on

Apply the selected protection automatically for users who prefer a consistent default posture.

Compatibility lists

Allow trusted mods or known services to communicate intentionally while retaining protections for everything else.

Responsible use

Privacy reduction, not invisibility.

Servers still receive an IP address and can observe account identity, movement, chat, timing, and server-side behavior. NullTrace narrows selected fingerprinting surfaces; it does not erase the connection.
