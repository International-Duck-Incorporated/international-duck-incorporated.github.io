The core

A pathfinder bot for Minecraft.

Given a goal — coordinates, a block, "follow that player" — Baritone plans and executes a route through the world: walking, jumping, climbing, bridging and breaking blocks as needed. Upstream it powers several well-known clients; the command interface (#goto, #stop and friends) is unchanged in the fork.

Why a fork

Kept current for Minecraft 26.x.

Upstream tracks older Minecraft releases. IDI maintains 26.1, 26.2 and 26.3 branches — the same version lines as Beacon, Venomous and ChampionsCode — with a GitLab CI pipeline that builds and publishes test results on every push.

Recent work

Look-and-aim behaviour.

Current development focuses on how the camera behaves while navigating: a walking head sway, an idle glance with its own speed, spin-up on direction changes, reaction pauses that never stall the aim, and state-machine tests that drive all four look behaviours through hostile runs.

In IDI's stack

Navigation behind Bagley.

Beacon's Bagley addon can drive Baritone when the opt-in Allow Baritone actions (ban risk) setting is on: baritone_go_to and baritone_stop map to the mod's #goto/#stop commands, advertised only while Baritone is actually installed.

Repository shape

One fork, three version lines.

The fork keeps upstream's multi-loader layout and adds IDI's version branches and CI on top.

01

Multi-loader tree

fabric/, forge/, neoforge/ and tweaker/ front-ends around the shared src/ pathfinding core, exactly as upstream ships them.

02

Version branches

26.1, 26.2 and 26.3 (the default branch) follow IDI's Minecraft targets, so Baritone builds against the same game versions as the rest of the organization's mods.

03

Upstream credit

Baritone was created by cabaletta and is licensed LGPL-3.0 with the upstream "anime exception". The IDI fork changes behaviour and version support; the credit and the license stay with upstream.
