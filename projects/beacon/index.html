A modular utility mod for Minecraft 26.2 and Fabric, built around quality-of-life tools, visual improvements, world utilities, persistent configuration, and a strict vanilla-server-safe policy.

Everyday tools

Five focused categories.

  • Render: Fullbright, Freecam, HUDs, Custom F3, and visual controls
  • World: Item Search, Light Level, Crop Progress, and Mob Stats
  • Utility: chat, inventory, reconnect, macros, audio, and session tools
  • Fun and Misc: cosmetic effects, alerts, timers, teams, and UI helpers
Project policy

Vanilla-server-safe.

Beacon intentionally excludes combat automation, movement automation, ESP and wallhacks, and server exploits. Its automation stays on the client and outside combat.

Configuration

State that persists.

  • Module state and per-module settings in config/beacon.json
  • Keybinds, favorites, and client preferences
  • Automatic configuration re-application on server join
  • Preserved configuration for temporarily absent addons
Extension

Addon-ready.

The Beacon addon API lets developers register additional modules without changing the core module implementation. The custom GUI exposes categories, search, favorites, settings, keybinds, configuration controls, and themes.

Engineering

A tested client foundation.

Dedicated verification tools cover Freecam, configuration semantics, and the user interface.

Freecam

A true detached camera with tick-based movement, configurable speed, optional collision, static view, and explicit interaction controls.

Atomic config

Versioned configuration, deferred saves, temporary files, and atomic moves reduce the risk of a truncated settings file.

UI verification

Python and Node-based checks exercise UI structure, runtime behavior, settings editing, keybinds, and configuration round trips.

Open development

Source, documentation, release notes, verification tools, issue tracking, and contribution workflows now live together on GitLab.
