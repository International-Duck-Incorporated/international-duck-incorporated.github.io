IDI Assets.

One flat media tree for the whole organization: project icons, logos and banners, config screenshots, the shared UI icon set, member and website art, and the 4K easter-egg video clips. Every distinct asset is stored exactly once and catalogued in manifest.csv.

What lives in the tree

Per-project folders, one copy each.

  • beacon/ 7 files: mod and GUI artwork
  • nulltrace/ 8 files: icon, logo, config screenshots
  • championscode/ 3 files: icon, logo, branding
  • venomous/, zonedout/, beacon-bagley/: project icons and logos
  • website/ 15 files: members, site art, video clips
  • ui-icons/ 22 files: shared Lucide/Heroicons SVG set
  • curseforge/ 9 files: listing logos, avatar, gallery
The catalogue

manifest.csv knows every byte.

One row per asset: project, kind, dimensions, size, SHA-256, how many duplicate copies were merged into it, all of their original paths and URLs, and a note on what the asset is. release-assets.csv separately catalogues release downloads (mod JARs, source archives and checksums), which are not part of this bundle.

Deduplication

116 files became 69.

The original snapshot held the same bytes copied into each project, the website and the platform listings: 116 files over 67 directories. The October 4, 2026 cleanup kept one copy of each distinct asset and shipped a path-mapping.csv of every old path. Nothing was lost: all 50 removed paths were byte-identical to a kept file, and no asset was re-encoded or edited.

Video

The easter-egg clip family.

The website folder holds easteregg-video.webm (24.4 s), easteregg-video-2.webm (5.4 s) and easteregg-video-3.webm (14.0 s), all 3840x2160 VP8 with Opus audio, plus the Beacon background video used on this site.

How it is used

The source of every picture IDI ships.

Project repositories, CurseForge listings and this website all draw their media from this bundle instead of carrying private copies.

01

Browse it raw

Every file is public in the repository tree; the manifest gives dimensions and hashes so downstream users can verify what they copied.

02

Attribution included

ATTRIBUTION.md records third-party material and licenses; the icon set is a shared Lucide/Heroicons-derived SVG collection.

03

Tagged and live

The project is public on GitLab under the assets tag and stays current as projects gain new artwork.
