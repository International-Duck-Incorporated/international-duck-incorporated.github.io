What lives in the tree

Edge blocklist

hall-of-shame.v2.bin & JSON.

Alongside visual media, idi-assets publishes the canonical hall-of-shame.v2.json feed and compact IDI2 binary index (hall-of-shame.v2.bin) consumed at the Cloudflare edge by IDI’s BadEgg gate across this site and Noosphere Chat.

Deduplication & attribution

Single canonical copy per asset.

Consolidates artwork that used to be duplicated across individual mod repositories and storefront listings into a single versioned tree, with third-party font, icon, and provider-monogram provenance documented in ATTRIBUTION.md.

How it is used

The source of every picture IDI ships.

Project repositories, CurseForge listings and this website all draw their media from this bundle instead of carrying private copies.

01

Browse it raw

Every file is public in the repository tree; the manifest gives dimensions and hashes so downstream users can verify what they copied.

02

Attribution included

ATTRIBUTION.md records third-party material and licenses; the icon set is a shared Lucide/Heroicons-derived SVG collection.

03

Tagged and live

The project is public on GitLab under the assets tag and stays current as projects gain new artwork.
