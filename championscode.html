ChampionsCode.

ChampionsCode is a client-side Fabric mod for Minecraft 26.3 that brings an msfconsole-inspired workflow to authorized, defensive server and plugin research, alongside an explicitly enabled runtime Java addon development system.

Research console

A terminal in game.

  • F8 opens a movable, resizable terminal with Console and Java tabs
  • clickgui and categorygui interfaces with typed option editors
  • Module registry with structured findings and explicit run controls
  • Command history, scrolling, colors, and confirmation redaction
Modules

Passive-first tooling.

  • Server fingerprint, connection posture, and plugin-surface audits
  • Wire-lens and session-trace packet observation
  • Container integrity, transaction echo, and motion evidence
  • Chat plugin enumeration with silent and bounded aggressive modes
Safety model

Authorization first.

  • Exact-host authorization allowlist validated on every run
  • One-run CONFIRM phrase and append-only JSONL audit log
  • Bounded, sequential probes with rate limits
  • No exploit delivery, credential collection, or stealth features
Development

Current position.

The alpha foundation builds, tests, and produces an installable Fabric JAR. Runtime Java addons compile real sources with a full JDK 25 behind developer mode and source-hash confirmation. No tagged release has been published yet.
