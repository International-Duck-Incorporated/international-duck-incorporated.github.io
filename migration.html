International Duck/Migration
September–October 2026

Why we moved
to GitLab.

International Duck Incorporated says it moved active development to GitLab after GitHub access disruptions affected its organization and member accounts. Public checks confirm that the GitHub organization, its repository pages, and the affected member profiles remain unavailable, while the GitLab group is public and active. The public roster now also includes @midas735, whose GitLab profile says “Member since October 05, 2026.” Support-ticket states were last shared by the team on October 7, 2026. This page separates team-reported support details from independently visible platform records.

CURRENT STATUS · OCTOBER 7, 2026Three support tickets in flight; GitLab active

Public checks still return 404 for IDI’s GitHub organization and repository pages, and for the @0xFFshell and @3spress0 profiles. GitLab’s group, now nine public projects, remains the verifiable source of record. Per the team’s support dashboard on October 7, 2026: the @3spress0 visibility appeal #4776851 is open, the organization reinstatement request #4828005 (opened October 6) is pending, and the @0xFFshell suspension appeal #4788849 is archived after the team closed it by mistake. GitHub Support has replied on the two live tickets asking how the accounts and the organization are used; the team has answered both.

The decision

Continuity over uncertainty.

The team says the move allowed development, releases, issue tracking, and collaboration to continue while the appeals remained open. Public GitLab records confirm continued project activity after the move; public records do not reveal GitHub’s internal rationale or review status.

What remains on GitHub

Metadata, not dependable access.

At the September 29 fact-check, GitHub’s aggregate organization API listed four repositories and five public members; the organization page, direct repository pages, individual repository API endpoints, and unauthenticated Git access were unavailable. GitLab publicly hosts all nine current, non-archived group projects and should be treated as IDI’s source of record.

Primary home

Development continues on GitLab.

GitLab’s public API lists nine non-archived group projects (most recently the Baritone fork and the idi-assets media bundle, both added in October 2026) and records project activity through October 6, 2026. With direct GitHub access still returning 404, GitLab is the currently verifiable source for code, releases, issues, and project history.
