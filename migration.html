International Duck/Migration
September–October 2026

Why we moved
to GitLab.

International Duck Incorporated says it moved active development to GitLab after GitHub access disruptions affected its organization and member accounts. Public checks confirm that the GitHub organization, its repository pages, and the affected member profiles remain unavailable, while the GitLab group is public and active. The public roster now also includes @midas735, whose GitLab profile says “Member since October 05, 2026.” This page separates team-reported support details from independently visible platform records.

CURRENT STATUS · OCTOBER 5, 2026GitHub remains unavailable; GitLab is active

Public checks return 404 for IDI’s GitHub organization, all four direct repository pages, and the @0xFFshell and @3spress0 profiles. GitHub’s aggregate organization API still lists limited metadata, but direct repository API requests and Git clone checks fail. GitLab’s group, six projects, and the @0xFFshell and @midas735 profiles are public. According to the team’s support records, no response has been received from GitHub for either ticket, #4776851 or #4788849, as of October 5, 2026.

The decision

Continuity over uncertainty.

The team says the move allowed development, releases, issue tracking, and collaboration to continue while the appeals remained open. Public GitLab records confirm continued project activity after the move; public records do not reveal GitHub’s internal rationale or review status.

What remains on GitHub

Metadata, not dependable access.

At the September 29 fact-check, GitHub’s aggregate organization API listed four repositories and five public members; the organization page, direct repository pages, individual repository API endpoints, and unauthenticated Git access were unavailable. GitLab publicly hosts all six current, non-archived group projects and should be treated as IDI’s source of record.

Primary home

Development continues on GitLab.

GitLab’s public API lists six non-archived group projects and records project activity through September 29, 2026. With direct GitHub access still returning 404, GitLab is the currently verifiable source for code, releases, issues, and project history.
