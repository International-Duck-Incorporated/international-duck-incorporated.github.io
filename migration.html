International Duck/Migration
September–October 2026

Why we moved
to GitLab.

International Duck Incorporated says it moved active development to GitLab after GitHub access disruptions affected its organization and member accounts. Public checks recorded in this timeline found the GitHub organization, repository pages, and affected member profiles unavailable; no newer public-access check accompanies this update, while the GitLab group remains public and active. In a GitHub Support email dated October 20, @3spress0 was told the account would remain restricted. The latest reported states for two other support tickets are from October 7. This page separates account-holder-reported support details from independently visible platform records.

CURRENT STATUS · OCTOBER 20, 2026GitHub says @3spress0 will remain restricted; GitLab is active

In a message dated October 20 at 01:29 UTC (03:29 CEST), GitHub Support said it had reviewed the account flags and decided the account should remain restricted, citing its Terms of Service and/or Acceptable Use Policies. It did not identify the specific flagged activity or say whether the appeal ticket is closed. The latest reported states of tickets #4828005 (pending) and #4788849 (archived) are from October 7; no newer update is available here. The public-access findings in this timeline predate the October 20 support email.

The decision

Continuity over uncertainty.

The team says the move allowed development, releases, issue tracking, and collaboration to continue while support requests were unresolved. On October 20, GitHub Support said @3spress0 should remain restricted. Public GitLab records confirm continued project activity after the move; they do not reveal GitHub’s internal rationale or the status of the other support cases.

What remains on GitHub

Metadata, not dependable access.

At the September 29 fact-check, GitHub’s aggregate organization API listed four repositories and five public members; the organization page, direct repository pages, individual repository API endpoints, and unauthenticated Git access were unavailable. GitLab publicly hosts all nine current, non-archived group projects and should be treated as IDI’s source of record.

Primary home

Development continues on GitLab.

GitLab’s public API lists nine non-archived group projects (most recently the Baritone fork and the idi-assets media bundle, both added in October 2026) and records project activity through October 6, 2026. In the latest public-access check recorded here (September 29, 2026), direct GitHub access returned 404; GitLab is the currently verifiable source for code, releases, issues, and project history.
