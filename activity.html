Scope

What this page tracks.

Every public repository in both organizations, and the newest 100 commits per repository per platform.

On the GitLab side (main) the feed covers Beacon, Venomous, NullTrace, ChampionsCode, Bagley, ZonedOut and this website. On the GitHub side (legacy mirror) the same projects are mirrored under the older organization. Commits are attributed to the six public members where the author identity matches a checked-in alias table; upstream OpSec contributors and automation accounts are bucketed separately.

If a platform's API is rate-limited or unreachable, the panels degrade independently and the footer sync state reports which sources answered, so the page keeps its checked-in content.
