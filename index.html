About

What International Duck builds.

International Duck Incorporated is an open-source collective publishing Minecraft mods, client utilities and developer tools. The work is client-side Java on Fabric and Meteor Client, released for free under GPL licences, with sources, releases and issue trackers on GitLab. The former GitHub organization is currently hidden from public view, so GitLab is the active source of truth. NullTrace and Beacon are additionally listed on CurseForge.

Everything is built in public: commit history, release notes and module registries are open, and this website mirrors the organization's live GitLab data so project status never goes stale. Read why the organization moved from GitHub to GitLab in September 2026, or follow the GitLab commit activity feed.
