About

What International Duck builds.

International Duck Incorporated publishes Minecraft mods, client utilities, defensive security gateways, and autonomous AI systems on GitLab. Client-side Fabric and Meteor Client mods carry per-repository open-source licences (GPL-3.0, LGPL-3.0, or MIT where stated), while this website and proprietary repositories are governed by IDI’s All Rights Reserved Licence. GitHub restrictions on the IDI organization were removed in October 2026, while GitLab remains an active development home; NullTrace and Beacon downloads are hosted on CurseForge.

Everything is built in public: commit history, release notes and module registries are open, and this website mirrors the organization's live GitLab data so project status never goes stale. Read why the organization moved from GitHub to GitLab in September 2026, or follow the GitLab commit activity feed.

Questions, bug reports or just saying hello: mail the team at 0xffshell@duck.com.
