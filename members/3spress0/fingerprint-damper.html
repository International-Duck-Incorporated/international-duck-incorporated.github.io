Fingerprint Damper.

A Manifest V3 Firefox extension that blunts passive browser fingerprinting at the JavaScript API layer using deterministic per-origin daily personas rather than per-call random noise. Complements network-layer blockers like uBlock Origin and Privacy Badger without breaking everyday websites, with zero runtime dependencies and zero data collection.

Design philosophy

API-layer damping without site breakage.

  • One stable persona per origin per day: per-call randomness is itself a detection signal; deterministic daily salts change cross-site hashes while staying consistent within a browsing session.
  • Blend into the largest crowd: hardware values normalize to common baselines rather than inventing unique synthetic configurations.
  • Leave bot-detection traps alone: surfaces like navigator.plugins are preserved so ordinary anti-bot checks are not tripped, and broken origins can be paused live from the toolbar popup.
Default protections (on by default)

Four low-risk passive shields.

  • Canvas & text metrics: up to 32 deterministic RGB low-bit flips on pixel serialization plus <0.01px measureText() jitter across HTML canvas and main-thread OffscreenCanvas.
  • WebGL identity & readback: normalizes vendor and renderer strings to Mozilla, hides WEBGL_debug_renderer_info, and applies stable low-bit noise to byte readPixels().
  • Hardware & battery: clamps hardwareConcurrency (and deviceMemory where present) to 8, and reports a full, charging BatteryManager shell.
Layered defense · Opt-in controls

Opt-in shields, DNR rules & lockdown.

Every higher-risk surface ships disabled with an explicit breakage note, paired with byte-reproducible .xpi builds and zero-dependency Node regression tests.

14 opt-in API switches

Granular surface controls

Includes AudioBuffer/AnalyserNode sample perturbation, non-relay WebRTC ICE filtering, ClientRects sub-pixel noise, 12-bit Math rounding, UTC and en-US defaults, speech/media device list hiding, and unsolicited notification prompt blocking.

DeclarativeNetRequest

78-domain ad & push blocklist

Optional static DNR ruleset (rules/adnets.json) blocking known push-ad SDKs and third-party tracking domains, plus boundary-aware ad service-worker registration guards.

Global lockdown tier

9 browser-enforced kill switches

Experimental CSP and network switches (script block, opaque-origin sandbox, worker and embed blocks, text-only mode, cookie/cache/header stripping) enforced by Firefox independently of page JavaScript.
