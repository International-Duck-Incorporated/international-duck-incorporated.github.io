Confluence OS.

A fast, zero-bloat Linux distribution built on Ubuntu 26.04 LTS ("Resolute") featuring a customized XFCE 4.20 top taskbar paired with a bottom Plank application dock under the Confluence-Dark ocean glass theme. Every Snap stub, telemetry agent, and background clutter daemon is removed and pinned out (Pin-Priority: -10).

Zero-Snap architecture

Clean APT + Flathub out of the box.

  • snapd, Snap transitional stubs, telemetry agents, and crash-reporting daemons are purged and APT-pinned at Pin-Priority: -10 so updates never pull Snap back onto the system.
  • Ships native .deb Mozilla Firefox via Mozilla's official signing key alongside a graphical Software Center configured for native APT packages and Flathub Flatpaks, including AppArmor bwrap profiles.
  • Preconfigured PipeWire + WirePlumber + Sound Open Firmware (SOF) audio and blueman Bluetooth management work immediately in both the live session and installed system.
Desktop & installer

Confluence-Dark XFCE 4.20 + Calamares 3.3.14.

  • Custom Confluence-Dark ocean glass GTK/XFWM4 theme pairing an XFCE 4.20 top status taskbar with a bottom Plank application dock.
  • Calamares 3.3.14 graphical disk installer with automated partitioning, LUKS2 full-disk encryption, Btrfs subvolume layouts, and hybrid BIOS + UEFI GRUB support.
  • Reproducible live-build pipeline written in Shell and Python with automated QEMU boot verification and checksummed ISO artifacts.
