About the roster

Who we are.

International Duck Incorporated has six public members. GitLab does not expose group membership through its public API, so this directory is a checked-in roster. Each card links to a profile page with the member's public account and, where available, project or activity details.

Commit attribution from the active GitLab source lives on the activity page. The former GitHub organization is currently hidden/private, so its API and mirror data are not used. Upstream contributors to forked projects and automation accounts are listed separately and are not counted as members.
