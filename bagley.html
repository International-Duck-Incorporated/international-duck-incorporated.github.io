Bagley.

An opt-in, client-side AI chat assistant distributed as a separate Fabric mod for Beacon. Bagley connects only to the OpenAI Chat Completions-compatible endpoint you configure locally.

Opt-in by design

Disabled until enabled.

Bagley is a separate addon rather than a built-in Beacon dependency. Install matching Beacon and Bagley builds, then enable the module explicitly in Beacon’s GUI.

Provider control

Your endpoint, your key.

The endpoint and API key live in config/beacon-bagley.json. They are deliberately kept outside Beacon’s configuration share-code system and should never be committed or shared.

Compatibility

Built per target.

Bagley is built once for each supported Minecraft version and uses Beacon’s public addon entrypoint, module registry, and configuration API.

Migration

Existing settings preserved.

On first enable, Bagley can migrate the former built-in Bagely configuration and memory files, preserve custom prompts, and update the old module entry through Beacon’s alias API.

Setup

Three deliberate steps.

Installation keeps the assistant, its provider access, and its memory under the player’s control.

01

Install matching builds

Add Fabric API, Beacon 1.9.0 or newer, and the Bagley build for the same Minecraft target to the mods folder.

02

Configure locally

Set an OpenAI-compatible endpoint and API key in the local Bagley configuration file.

03

Enable explicitly

Turn Bagley on in the Beacon GUI and choose whether optional conversation memory fits your privacy needs.

Privacy boundary

Credentials stay out of shared settings.

Bagley’s endpoint, API key, and optional conversation memory are local-only concerns. Review the complete guide before connecting the addon to any provider.
